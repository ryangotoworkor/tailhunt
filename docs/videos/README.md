Teaching videos go here (added by the narration pipeline, not by hand):

- `<part>.mp4` for each part in `video/parts.json`: p0-overview, p1-alert, p2-trace, p3-pool, p4-fix, p5-analysis, p6-runbook
- `problems/<id>.mp4` for each problem in `video/problems.src.json` (q01 … q09)

Until a file exists, the web UI shows 「视频待生成」 in its place.
